# Интеграция входящих заявок

Документ описывает контракт для будущих интеграций с Telegram, WhatsApp, Instagram, сайтом и другими внешними источниками.

Главное правило:

```text
Интеграция создает только заявку.
Интеграция не создает заказ.
Заказ создается только после подтверждения сотрудником CRM.
Общий поток

Клиент пишет в чат-бот
↓
Бот собирает данные клиента, автомобиля и услуги
↓
Бот отправляет данные в CRM
↓
CRM создает контакт заявки
↓
CRM создает входящую заявку
↓
Менеджер проверяет заявку
↓
Менеджер выбирает реальную услугу CRM
↓
Менеджер подтверждает заявку
↓
CRM создает обычный заказ
Endpoint

POST /integrations/leads
Локальный адрес в development:

http://127.0.0.1:8000/integrations/leads
Авторизация интеграции

Каждый запрос должен передавать integration token в header:

x-integration-token: dev-integration-leads-token-change-me
Значение токена берется из переменной окружения backend:

INTEGRATION_LEADS_TOKEN=dev-integration-leads-token-change-me
Для production нужно заменить значение на длинный случайный секрет.

Разрешенные источники

Поле source может принимать значения:

telegram
whatsapp
instagram
website
bot
Ручные заявки из CRM создаются через обычный /leads, а не через /integrations/leads.

Payload

Пример тела запроса:

{
  "source": "telegram",
  "client_name": "Клиент из Telegram",
  "phone": "+77001112233",
  "message": "Здравствуйте, хочу записаться на полировку",
  "car_brand": "BMW",
  "car_model": "M5",
  "car_year": 2021,
  "car_color": "Черный",
  "plate_number": "123ABC02",
  "preferred_time": "На выходных после обеда",
  "comment": "Заявка создана через Telegram-бота",
  "external_user_id": "123456789",
  "external_username": "@telegram_client",
  "items": [
    {
      "service_name_text": "Полировка",
      "quantity": 1,
      "comment": "Клиент написал из Telegram"
    }
  ]
}
Поля заявки

source

Источник заявки.

Примеры:

telegram
whatsapp
instagram
website
bot
Обязательное поле.

client_name

Имя клиента.

Пример:

Надир
Необязательное поле, но желательно собирать его в боте.

phone

Телефон клиента.

Пример:

+77001112233
Обязательное поле.

По этому телефону CRM будет пытаться связать заявку с уже существующим клиентом.

message

Исходное сообщение или краткое описание запроса клиента.

Пример:

Хочу узнать цену на полировку и химчистку.
Необязательное поле.

car_brand

Марка автомобиля.

Пример:

BMW
Желательное поле.

car_model

Модель автомобиля.

Пример:

M5
Желательное поле.

car_year

Год выпуска автомобиля.

Пример:

2021
Необязательное поле.

car_color

Цвет автомобиля.

Пример:

Черный
Необязательное поле.

plate_number

Госномер автомобиля.

Пример:

123ABC02
Необязательное поле.

Если госномер указан, CRM сможет точнее избежать дублей автомобилей.

preferred_date

Желаемая дата записи.

Формат:

ISO datetime
Пример:

2026-05-26T10:00:00
Необязательное поле.

preferred_time

Желаемое время в свободном текстовом формате.

Пример:

На выходных после обеда
Необязательное поле.

comment

Внутренний комментарий от интеграции.

Пример:

Заявка создана через Telegram-бота.
Необязательное поле.

external_user_id

ID пользователя во внешней системе.

Примеры:

Telegram user id: 123456789
WhatsApp id: 77001112233@c.us
Instagram user id: 987654321
Необязательное поле, но для ботов желательно передавать.

CRM использует source + external_user_id, чтобы понять, что это тот же человек, если он написал повторно.

external_username

Username или никнейм пользователя во внешней системе.

Примеры:

@telegram_client
@instagram_client
Необязательное поле.

items

Список интересующих услуг.

Обязательное поле.

Минимум одна услуга.

Каждый item содержит:

{
  "service_name_text": "Полировка",
  "quantity": 1,
  "comment": "Клиент интересуется полировкой кузова"
}
Важное правило:

Бот отправляет услугу текстом.
Бот не должен отправлять service_id.
Менеджер сам выбирает реальную услугу CRM перед подтверждением заказа.
Это нужно, чтобы бот не создавал неправильные заказы и не ломал pricing.

Главные поля:

{

  "lead_contact_id": 4,

  "status": "new",
  "client_name": "Клиент из Telegram",
  "phone": "+77001112233",

  "items": [
    {
      "id": 21,
      "service_name_text": "Полировка",
      "quantity": 1

После этого бот может ответить клиенту:

Спасибо! Ваша заявка принята.
Номер заявки: #15.

Возможные ошибки

401 — integration token не передан

Причина:

Нет header x-integration-token
403 — неверный integration token

Причина:

Передан неправильный x-integration-token
400 — неверный source

Причина:

source не входит в список разрешенных источников
Разрешенные значения:

telegram
whatsapp
instagram
website
bot
400 — не указан телефон

Причина:

phone пустой
400 — нет услуг

Причина:

items пустой
400 — пустое название услуги

Причина:

service_name_text пустой

Сценарий вопросов для Telegram-бота

Минимальный сценарий:

1. Здравствуйте! Я помогу оставить заявку в Imperial Detailing.
2. Как вас зовут?
3. Укажите номер телефона.
4. Какая у вас марка автомобиля?
5. Какая модель автомобиля?
6. Укажите год выпуска, если знаете.
7. Укажите цвет автомобиля, если хотите.
8. Укажите госномер, если хотите.
9. Какая услуга вас интересует?
10. Когда вам удобно приехать?
11. Есть ли комментарий или пожелания?
12. Подтвердите заявку.
После подтверждения бот отправляет данные в CRM.

Сообщение клиенту после создания заявки

Спасибо! Ваша заявка принята.

Номер заявки: #15.
Менеджер Imperial Detailing скоро свяжется с вами для подтверждения записи.
Важные правила

1. Бот не создает заказ.
2. Бот не выбирает service_id.
3. Бот не применяет pricing.
4. Бот не принимает оплату.
5. Бот не меняет статусы заказов.
6. Бот только создает входящую заявку.
7. Решение о создании заказа принимает сотрудник CRM.
Будущее развитие

Позже можно добавить:

- отдельный bot-service
- Telegram bot
- WhatsApp integration
- Instagram integration
- web form integration
- уведомления менеджерам о новых заявках
- автоматическое определение услуги по тексту через AI
- AI-подсказки, но только с подтверждением менеджера
AI не должен автоматически создавать заказ или применять финансовые решения без подтверждения сотрудника.
